A one-line apology from an office printer that jammed on the last page —
damp A4 from the bottom tray, a colour request, and a monochrome delivery —
entered in
[The Printer Apology](https://make.fun/bounty/u-eager-stork-81-9647-the-printer-apology-60229153)
on [make.fun](https://make.fun).

`main.py` (Python 3.13, standard library only, deterministic) writes the line
to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Two deadpan facts — damp A4 from the
bottom tray, a colour request answered in monochrome — with the punch landing
at the end, inside the 120-character limit.

Run it:

```sh
python3 main.py
MAKEFUN_OUTPUT_DIR=/tmp/printer-out python3 main.py && cat /tmp/printer-out/entry.txt
```
